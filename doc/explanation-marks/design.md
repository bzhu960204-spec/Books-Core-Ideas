# 讲解片段收藏（Explanation Marks）设计文档

> **状态**：已实现。最终落地的交互、与本文的偏差（如常驻高亮、浮动菜单定位）见 [implementation.md](./implementation.md)；以其为准。

> 在**单本书内部**收集 AI 讲解（Explanation / 详解）正文里的关键片段：记录"这段文字 + 它的位置"，汇总到这本书自己的"片段收藏"入口；点击任意一条即可跳回对应章节的讲解并定位到该段落。

---

## 1. 功能概述

阅读一章的**讲解（详解）**时，经常会遇到关键的观点或段落，希望把它们**原地记下来、之后能快速回到那个位置重读**。

本功能提供这样一个"片段书签"：

- 在讲解查看态**选中一段文字**即可收藏（可附一句批注）。
- 每本书有一个**"片段收藏"入口**，按章节分组列出本书全部收藏片段。
- 点击任意一条 → 打开其所属章节的讲解，**滚动并短暂闪烁**定位到该片段。

### 1.1 与现有"阅读书签"的区别

| | 阅读书签 `ReadingBookmark` | 片段收藏 `ExplanationMark`（本功能） |
|---|---|---|
| 目的 | 记"我读到哪"（阅读进度） | 记"这段关键文字 + 它的位置" |
| 锚定 | 整篇的滚动百分比 `scrollRatio` | 选中文本（引用 + 上下文）+ 字符偏移 |
| 数量 | 追加式时间线，最新一条驱动"继续阅读" | 每本书多条，构成"片段收藏" |
| 入口 | 阅读历史页（跨书时间线） | **书内**的"片段收藏"面板 |
| 携带内容 | 可选备注 | 片段原文 `quote` + 可选批注 `note` |

> 两者互不影响、独立存储。片段收藏**不参与**"继续阅读"逻辑。

### 1.2 本期范围（明确边界）

**做**：书内收集片段 + 列表查看 + 点击跳转定位（滚动 + 闪烁）。

**不做（留作后续）**：

- 跨书的"片段 Bank"聚合页。
- 把片段以 `<mark>` 的形式在讲解正文里**常驻内联高亮**重现。
- 高亮颜色 / 分类 / 标签。

## 2. 命名与领域定位

命名为 **`ExplanationMark`（讲解片段 / 片段收藏）**，刻意避开仓库中已占用的概念：

- `Excerpt`（章节**摘录**，摘自原书的引文）
- `BookCollection`（**书**的合集）
- `ReadingBookmark`（阅读**进度**书签）

领域关系（挂在 `Chapter` 下，与 `ReadingBookmark` 同级）：

```
Book → Chapter → ChapterExplanation (0:1, content 为富文本 HTML)
                └── ExplanationMark[]  ← 本功能：针对该章讲解正文的片段收藏
```

## 3. 核心难点：片段定位（锚定）策略

讲解正文 `ChapterExplanation.content` 是**可被富文本编辑器整体改写的 HTML**，因此不能用脆弱的 DOM 节点路径做唯一定位。采用业界标准（W3C Web Annotation / Hypothesis）的**双重锚点**，但**本期仅用于"跳转定位"，不做常驻高亮**：

1. **TextQuoteSelector（主锚，稳健）**
   - `quote`：选中的纯文本。
   - `prefix` / `suffix`：选区前后各约 30~50 字的上下文。
   - 作用：重开讲解后，在渲染正文的**纯文本**里搜索 `prefix + quote + suffix` 来命中位置，容忍段落结构/字体变化。

2. **TextPositionSelector（辅锚，消歧 / 兜底）**
   - `startOffset` / `endOffset`：选区在正文**纯文本**中的字符偏移。
   - 作用：当 `quote` 在正文里出现多次时，用偏移就近优选；主锚失效时用偏移估算滚动比例兜底。

### 3.1 跳转流程

```
点击某条片段
   └─ 打开该章讲解 Modal（查看态）
        └─ 等待正文渲染
             ├─ 在正文纯文本中用 prefix+quote+suffix 定位
             │    ├─ 命中 → 滚动到该位置并短暂闪烁（临时 DOM 效果，不写回 content）
             │    └─ 多处命中 → 取离 startOffset 最近的一处
             └─ 未命中（讲解被大改）
                  └─ 按 startOffset 估算滚动比例，滚到附近；列表项标注"⚠ 位置可能已变"
```

> **重要**：定位全程不修改数据库中的 `content`，闪烁只是运行时在 DOM 上临时加/移除一个 CSS class。原文内容零污染。

### 3.2 收藏时如何采集锚点（前端）

在讲解查看态（`dangerouslySetInnerHTML` 渲染的容器内）：

1. 监听 `selectionchange` / `mouseup`，拿到非空 `window.getSelection()`。
2. 以**正文根节点的纯文本**为基准，计算选区的 `startOffset` / `endOffset`
   （用 `Range` + `TreeWalker` 累加文本节点长度得到纯文本偏移）。
3. 从纯文本中截取 `prefix`（start 前 N 字）、`quote`（选区文本）、`suffix`（end 后 N 字）。
4. 对空白做归一化（折叠连续空白）后再存，保证跨渲染一致。

## 4. 数据模型

### 4.1 实体 `ExplanationMark`

新增 `com.bookscoreideas.entity.ExplanationMark`，风格对齐 `ReadingBookmark`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT PK | 自增 |
| `book` | ManyToOne → `Book`（`book_id`，NOT NULL，`@JsonIgnore`） | 冗余存书，驱动"本书片段收藏"查询 + 级联删除 |
| `chapter` | ManyToOne → `Chapter`（`chapter_id`，NOT NULL，`@JsonIgnore`） | 片段所在章节 |
| `quote` | CLOB | 选中的纯文本片段本身（列表直接展示） |
| `prefix` | VARCHAR(200) | 前文上下文（定位用） |
| `suffix` | VARCHAR(200) | 后文上下文（定位用） |
| `startOffset` | INT | 纯文本起始偏移（辅锚 / 兜底） |
| `endOffset` | INT | 纯文本结束偏移 |
| `note` | VARCHAR(1000) | 可选批注 |
| `createdAt` | TIMESTAMP | `@PrePersist` 落时间 |
| `updatedAt` | TIMESTAMP | `@PreUpdate` 更新时间 |

在 `Chapter` 实体中增加一个 `@OneToMany(mappedBy="chapter", cascade=ALL, orphanRemoval=true)` 的 `explanationMarks` 集合（`@JsonIgnore`），与现有 `bookmarks` 完全一致，使删章/删书级联清理。

### 4.2 数据库迁移 `V7__add_explanation_marks.sql`

沿用现有迁移的 `IF NOT EXISTS` 幂等写法（兼容 Hibernate `ddl-auto=update` 已建表的情况）：

```sql
-- V7: Explanation marks —— 书内讲解正文的片段收藏（文字 + 定位）。
CREATE TABLE IF NOT EXISTS EXPLANATION_MARKS (
    ID           BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    BOOK_ID      BIGINT NOT NULL,
    CHAPTER_ID   BIGINT NOT NULL,
    QUOTE        CLOB,
    PREFIX       VARCHAR(200),
    SUFFIX       VARCHAR(200),
    START_OFFSET INTEGER,
    END_OFFSET   INTEGER,
    NOTE         VARCHAR(1000),
    CREATED_AT   TIMESTAMP,
    UPDATED_AT   TIMESTAMP,
    CONSTRAINT FK_EXPL_MARK_BOOK    FOREIGN KEY (BOOK_ID)    REFERENCES BOOKS(ID),
    CONSTRAINT FK_EXPL_MARK_CHAPTER FOREIGN KEY (CHAPTER_ID) REFERENCES CHAPTERS(ID)
);

CREATE INDEX IF NOT EXISTS IDX_EXPL_MARK_BOOK    ON EXPLANATION_MARKS(BOOK_ID);
CREATE INDEX IF NOT EXISTS IDX_EXPL_MARK_CHAPTER ON EXPLANATION_MARKS(CHAPTER_ID);
```

> 版本号 `V7` 以提交时实际最新迁移为准（当前最新为 `V6`）。

## 5. 后端 API

新增 `ExplanationMarkRepository`、`ExplanationMarkController`（`@RequestMapping("/api")`），风格对齐 `ReadingBookmarkController`。

| 方法 & 路径 | 说明 | 请求体 | 响应 |
|---|---|---|---|
| `POST /api/chapters/{chapterId}/marks` | 收藏一个片段 | `{ quote, prefix, suffix, startOffset, endOffset, note? }` | 新建片段 DTO |
| `GET /api/books/{bookId}/marks` | **本书全部片段收藏**（核心入口） | — | 片段 DTO 列表（建议按 章节 orderIndex，再按 startOffset / createdAt 排序） |
| `PATCH /api/marks/{id}` | 编辑批注 | `{ note }` | 更新后的片段 DTO |
| `DELETE /api/marks/{id}` | 删除片段 | — | 204 |

可选（便于单章刷新）：`GET /api/chapters/{chapterId}/marks` —— 本期非必须，列表数据已可由书级接口获得。

### 5.1 DTO 字段（`toMap`）

```
id, bookId, bookTitle, chapterId, chapterTitle,
quote, prefix, suffix, startOffset, endOffset, note,
createdAt, updatedAt
```

> 与 `ReadingBookmarkController.toMap` 同样手工拼 `Map<String,Object>`，带上 `chapterTitle` 便于前端分组展示，无需二次查询。

### 5.2 Repository 方法

```java
List<ExplanationMark> findByBookIdOrderByChapter_OrderIndexAscStartOffsetAscIdAsc(Long bookId);
List<ExplanationMark> findByChapterIdOrderByStartOffsetAscIdAsc(Long chapterId);
```

## 6. 前端设计

### 6.1 API 封装（`frontend/src/api.js`）

新增 `markApi`，对齐现有 `bookmarkApi`：

```js
export const markApi = {
  create: (chapterId, mark) => apiFetch(`${API_BASE}/chapters/${chapterId}/marks`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(mark),
  }),
  listByBook: (bookId) => apiFetch(`${API_BASE}/books/${bookId}/marks`),
  updateNote: (id, note) => apiFetch(`${API_BASE}/marks/${id}`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ note }),
  }),
  delete: (id) => apiFetch(`${API_BASE}/marks/${id}`, { method: 'DELETE' }),
};
```

### 6.2 收藏片段（`ChapterExplanationModal.jsx`）

在**查看态**正文容器（当前 `bodyRef`）内：

- 监听选区，选中非空文本时，在选区附近浮出一个小工具条："📑 收藏此片段"。
- 点击后：
  1. 用 `Range` + 正文根节点计算 `startOffset/endOffset` 及 `prefix/quote/suffix`（见 §3.2）。
  2. 可选：弹一个轻量输入框填 `note`。
  3. 调 `onSaveMark?.({ quote, prefix, suffix, startOffset, endOffset, note })`，由 `BookDetailPage` 落库。
- 保存成功给一个短暂的"✓ 已收藏"反馈（复用现有 `bookmarkSaved` 式的瞬时提示）。

> 采集偏移的工具函数（`getPlainTextOffsets(rootEl, range)` 等）建议放到 `frontend/src/utils/` 下独立文件，便于复用与单测。

### 6.3 定位跳转（`ChapterExplanationModal.jsx`）

新增可选 prop `initialAnchor = { quote, prefix, suffix, startOffset, endOffset }`：

- 在现有"恢复滚动位置"的 `useEffect`（当前依赖 `initialScrollRatio`）旁，增加 anchor 分支：
  - 渲染完成后（`requestAnimationFrame`），在正文纯文本中用 `prefix+quote+suffix` 定位到对应 DOM `Range`。
  - `range.getBoundingClientRect()` → 计算容器 `scrollTop`，滚动过去。
  - 给命中区域包一层临时 `<span class="mark-flash">` 或对最近块级元素加 `.mark-flash` class，1.5s 后移除（纯运行时，不改 `content`）。
  - 未命中 → 回退：`startOffset / totalPlainTextLength` 估算比例，复用 `initialScrollRatio` 的滚动逻辑。

对应 CSS（`index.css`）加一个 `@keyframes` 闪烁（背景色短暂高亮后淡出）。

### 6.4 本书"片段收藏"入口（`BookDetailPage.jsx`）

- **入口**：书籍头部工具区加按钮 **"📑 片段收藏 (N)"**（N 为本书片段数，随 `markApi.listByBook` 加载）。与现有"继续阅读"等头部操作同一区域，风格一致。
- **面板**：点击打开一个 Modal（复用 `Modal.jsx`），内容为**按章节分组**的片段列表：
  - 分组标题：章节名。
  - 每条：片段文字 `quote`（截断显示）+ 批注 `note` + 时间；行内操作「跳转」「编辑批注」「删除」。
  - 空态：引导"在讲解里选中文字即可收藏"。
- **跳转**：点「跳转」→ 复用现有 deep-link 机制（`openExplanation(chapterId, false, ...)`），但传入 `initialAnchor` 而非 `initialScrollRatio`，打开后由 Modal 完成定位闪烁。
- **状态**：`BookDetailPage` 持有 `marks` 列表与打开/关闭面板的状态；`onSaveMark` / 删除 / 改批注后就地更新列表与计数。

### 6.5 章节角标（可选，轻量）

在章节行（已有 explanation 角标、bookmark 角标处）加一个"有收藏片段"的小标记，点击可直接打开该章并展开其片段。非必需，可随 Phase 3 一起或延后。

## 7. 边界与降级

| 场景 | 处理 |
|---|---|
| 讲解被大幅改写，锚点找不到 | 不报错；按 `startOffset` 估算滚动兜底；列表项显示"⚠ 位置可能已变" |
| `quote` 在正文出现多次 | 取离 `startOffset` 最近的一处 |
| 选区跨多个块/空选区 | 空选区不显示收藏按钮；跨块仍以纯文本 `quote/prefix/suffix` 处理 |
| 讲解被删除 | 级联（`orphanRemoval`）清除该章片段 |
| 章节 / 书被删除 | 级联清除（外键 + JPA cascade） |
| 超长片段 | `quote` 用 CLOB 不限长；列表展示截断，详情可展开 |
